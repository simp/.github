## SIMP: System Integrity Management Platform

SIMP is the open-source core of **Sicura Community**, from [Sicura](https://www.sicura.us/). It is a framework for automating security compliance on Linux systems: Puppet modules, tooling and documentation that configure Enterprise Linux hosts (RHEL, Rocky, AlmaLinux, Oracle Linux and CentOS Stream) toward standards such as DISA STIG and CIS Benchmarks, and keep them there.

More of Sicura's open-source work, including compliance data and OpenVox tooling, lives at [github.com/sicuraus](https://github.com/sicuraus).

### Get involved

- **Found a bug, want a feature, or have a question?** Open an issue in the relevant repository. Each module's README says which repository that is.
- **Want to contribute a fix?** Pull requests are welcome. Every change is reviewed by a maintainer before it merges.
